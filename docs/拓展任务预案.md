# 拓展任务预案（比赛现场用）

> 现场公布拓展任务后，先对照本文档「已内置能力」直接演示；如果是新任务，按「快速扩展指南」三步接入。

## 一、已内置的拓展能力（可直接演示）

### 1. AI 助教「小智」
- **位置**：任意页面右下角悬浮球 🤖（全局可用）
- **能力**：数据感知问答——项目进度、错题分析、专注报告、排行榜名次、学习建议、签到状态、情绪鼓励；打字机流式输出、快捷问题、思考中状态
- **1 分钟演示脚本**：点开悬浮球 → 依次点快捷问题「看看我的项目进度」「我现在排第几名」→ 展示它能说出具体项目的完成百分比和名次分差 → 手动输入「给我一些学习建议」看综合建议
- **技术要点**：`AiAssistant.vue`，意图正则匹配 + 并行拉取 mock 接口 + 本地 store 数据融合；如现场要求接真大模型，只需把 `composeAnswer` 换成一次 OpenAI 兼容接口调用

### 2. 排行榜
- **位置**：侧边栏「排行榜」（学生/教师/管理员菜单均有）
- **能力**：总榜/本周双榜，前三名领奖台 + 完整榜单，综合积分 = 最佳闯关×0.5 + 专注分钟 + 打卡×2，高亮"我"的位置与分差
- **1 分钟演示脚本**：打开排行榜 → 切「本周」看变化 → 指出绿色高亮行是当前登录学生 → 教师账号登录可看全组
- **技术要点**：mock 接口 `GET /api/leaderboard?scope=total|week`（`handlers.ts`），页面 `Leaderboard.vue`

### 3. 结题证书生成 + 打印
- **位置**：项目详情 →「成果档案」→ 项目已结题后，卡片右上「🎓 生成结题证书」
- **能力**：自动汇总成员、历时天数、任务完成数、打卡数生成证书；含编号、指导教师落款（取自批注作者）、红章；打印时只输出证书，可"另存为 PDF"
- **1 分钟演示脚本**：登录 student → 打开已结题项目 p2 的成果档案 → 点生成证书 → 点打印（现场选取消，讲打印隔离即可）
- **技术要点**：`ArchivePanel.vue`，`body.printing-certificate` + `@media print` 的 visibility 隔离方案

### 4. 学习周报
- **位置**：「成长档案」页，「本周专注趋势」下方
- **能力**：近 7 天专注分钟、闯关次数与最佳分、签到天数，附小智 rule-based 点评
- **技术要点**：`Profile.vue` 的 `weekReport` computed；依赖 mock `GET /api/quiz/stats` 新增的 `recent` 字段

### 5. Ctrl+K 全局搜索
- **位置**：任意页面按 `Ctrl+K`（Mac `⌘K`）
- **能力**：跨「页面 / 项目 / 资源库」三类目标即时搜索，Enter 打开第一项
- **1 分钟演示脚本**：按 Ctrl+K → 输入「火星」→ 展示项目命中并跳转 → 输入「电路」→ 资源命中
- **技术要点**：`Layout.vue` 全局 keydown + 250ms 防抖搜索资源

## 二、高概率现场拓展任务预测（未实现项 + 思路）

| 预测任务 | 概率 | 若被抽中怎么快速做 |
|---|---|---|
| 接入真 LLM（AI 点拨/作文批改） | 高 | 小智已留好壳：`AiAssistant.vue` 的 `composeAnswer` 改为 fetch 后端 `/api/ai/chat`；mock 侧再加一条 SSE 路由即可 |
| 导出数据（CSV/Excel/成绩单） | 高 | 前端 `Blob` + `URL.createObjectURL` 导出即可，数据源用现成列表接口；10 分钟工作量 |
| 多题型（多选/填空/判断） | 中 | `db.ts` 题目结构加 `type` 字段，`validateQuestionBody` 按类型分支；答题端先只改 Quiz.vue（LessonPlayer/Battle 可暂不支持并过滤） |
| 国际化（中英切换） | 中 | 工程量大，可退而求其次：设置页加"英文模式"只翻译导航与首页高频文案，演示切换即可 |
| 防沉迷/健康提醒 | 中 | Layout 加 `setInterval`（演示时可设 30 秒档位）触发 `notification.warning`，设置页加开关 |
| PWA/离线缓存 | 中 | `vite-plugin-pwa` 插件 + manifest，半小时内可完成 |
| 家长端/第三角色 | 低 | mock 已有角色分级体系（ROLE_RANK），加 `parent` 角色 + 只读路由守卫即可 |
| 视频讲解/富媒体课件 | 低 | 课程数据在 `src/data/courses.ts`，给 lesson 加 `videoUrl` 字段，LessonPlayer 换 `n-video`/iframe |

## 三、快速扩展指南：给 mock 加一个新接口（三步）

1. **db.ts**：需要新表就加 `interface XxxRec` + `DB` 接口字段 + seed 数据；注意 `SCHEMA_VERSION` 要 +1（否则旧 `.mock-data/db.json` 不会重播种子）
2. **handlers.ts**：在 `routes` 数组加一条 `{ method, pattern: /^\/api\/xxx$/, handler }`，权限用 `rankOf(ctx.user)` / `memberOf(...)` 校验
3. **前端**：`src/api/` 新文件用现成 `get/post/patch/del`；`types.ts` 补类型；页面照抄 `Resources.vue` 的 load/try-catch 模式；路由加进 `router/index.ts`，菜单加进 `Layout.vue`

## 四、演示注意事项

- **清场复位**：演示前删除 `.mock-data/` 目录再启动，恢复全新种子数据（约 2 分钟重建演示状态）
- **演示账号**：`student / teacher / schooladmin / admin / superadmin`，密码均为 `123456`
- **排行榜有数据**：种子已给 u1–u4 配好闯关成绩与专注记录，总榜/周榜都有区分度
- **结题项目**：`student` 账号下的《校园智能垃圾分类助手》（p2）已结题，直接可出证书
- **多浏览器**：开两个窗口分别登 student / teacher，演示"批注实时同步"（5 秒轮询）
- 启动命令：`yarn install && yarn dev` → http://localhost:5173
